## ✨ 核心特性

- 📷 **经典拍立得相纸美学**：
  - 经典白边相纸比例（1:1 正方形相框 + 标志性留白下巴），真实还原胶片冲印质感。
- ✍️ **手写体寄语与日期**：
  - 模拟真实拍立得下方的复古油墨手写字迹，支持自由修改。
- 🌈 **4 种全息光影镀膜**：
  - 彩虹极光 / 落日霞光 / 赛博霓虹 / 经典纯净。
- 🕹️ **3D 物理悬浮与光斑反射**：
  - 鼠标在照片上滑过时，卡片随光标自然倾斜，胶片表面折射通透高光。
- 📱 **手机陀螺仪体感支持**：
  - 手机浏览器打开直接倾斜手机即可体验。
- 📸 **3x 超高清 PNG 导出**：
  - 完美导出无畸变、带有真实相纸质感的拍立得图片。
