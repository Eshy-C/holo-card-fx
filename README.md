## ✨ 核心特性

- 🎛️ **全方位光影与全息微调控制台**：
  - **全息镀膜强度 (0% ~ 100%)**：自由调节彩虹折射浓度。
  - **胶片高光反光 (0% ~ 100%)**：微调玻璃胶片表面的光线反光硬度。
  - **4 种全息色调**：彩虹极光 / 落日霞光 / 赛博霓虹 / 流金璀璨。
- 🎞️ **胶片影调与暗角滤镜**：
  - 曝光亮度 / 对比度 / 色彩饱和度 / 复古暖色温 / 边缘暗角暗化 / 内框圆角。
- 📄 **4 种经典相纸底色**：
  - 经典纯白 / 复古暖米 / 落樱浅粉 / 曜石黑卡。
- ✍️ **手写寄语与 5 款油墨颜色**：
  - 中性黑 / 钢笔蓝 / 复古红 / 金色油墨 / 白银油漆笔。
- 🔄 **一键重置 (Reset)**：随时一键恢复初始黄金参数。
- 📸 **3x 超高清 PNG 导出**：无畸变、100% 还原调色与光影细节。
